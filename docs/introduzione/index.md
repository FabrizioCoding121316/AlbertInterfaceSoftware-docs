# **INTRODUZIONE**

Software creato con la libreria `PySide6` (QT) per il robot che fa parte del progetto del **Laboratorio di Robotica** dell'[IIS Albert Einstein di Vimercate](https://einsteinvimercate.edu.it/) creato dagli studenti, questo software ha delle funzionalità come una interfaccia interattiva con una faccina che segue a colui che la guarda, in più ha delle opzioni di assitente inteligente con AI e una parte di controllo manuale per gli operatori, tutto ciò dentro un'app fatto specificamente per il raspberry PI 5 su raspberry PI OS e altre distro di linux.

Il software è basato su una prima versione del progetto fatto con l'aiuto di **Claude** e poi riscritto totalmente su `python` per non avere il bisogno di creare un server.
